# Murmuration

Up to four million particles, simulated on the graphics card every frame, that spell any word you type and morph into a galaxy, Saturn, a torus knot, DNA and a Lorenz attractor.

Live: https://saksham.digital/murmuration/

The word lives in the link: `https://saksham.digital/murmuration/#your-name` opens already spelling it.

Move through the swarm to push it, click to detonate, drag to orbit, scroll to zoom, keys 1 to 6 for shapes. One HTML file, three.js r128, needs WebGL 2 with float textures.
